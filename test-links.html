🔗 批量文档转换器 - 链接选择测试页面

📋 测试说明：
  1. 点击浏览器扩展图标打开弹窗
  2. 点击"开始选择链接"按钮
  3. 页面右下角应该出现蓝色状态指示器，显示操作提示
  4. 🎯 核心操作：
    • Command + 点击（Mac）或 Ctrl + 点击（Windows）= 选择链接（绿色边框）
    • 普通点击 = 正常打开链接（方便在新页面继续选择）
  5. 按ESC键可以退出选择模式
  6. 选择完成后，点击弹窗中的"处理中队内容"按钮进行批量转换
