Markdown 转换样式测试

这个页面用于测试新的 MarkDownload 风格转换是否生效。

1. 表格测试

预期效果：表格应该对齐，表格内链接被剥离，文本居中

功能 状态 描述
表格美化 启用 表格对齐和格式化
代码块 启用 语言识别和语法高亮
链接处理 启用 表格内链接剥离

2. 代码块测试

预期效果：代码块应该有语言标识，格式规范

function testMarkdown() {
    const table = document.querySelector('table');
    const rows = table.querySelectorAll('tr');
    
    rows.forEach(row => {
        const cells = row.querySelectorAll('td, th');
        cells.forEach(cell => {
            console.log(cell.textContent);
        });
    });
}

使用说明

  1. 确保扩展已刷新（在 chrome://extensions/ 中点击刷新按钮）
  2. 使用扩展选择此页面内容
  3. 查看转换后的 Markdown 是否具有以下特征：
    • 表格对齐且美观
    • 表格内链接被剥离（只保留文本）
    • 代码块有语言标识（如 ```javascript）
    • 普通链接保持完整格式
